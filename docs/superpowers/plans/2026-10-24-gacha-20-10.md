# Gacha Hoa 20/10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web gacha capsule cho 5 người nhận ngẫu nhiên 5 lọ hoa 20/10 (không trùng), có trang admin chỉnh quà và lời chúc.

**Architecture:** SPA Vite + React nói chuyện trực tiếp với Firebase (Firestore + Auth), không có server riêng. Logic bốc thăm là hàm thuần `computeDraw` được bọc trong `runTransaction` trên một document `game/state`, nên test được không cần Firebase. Quà và lời chúc nằm trong Firestore để admin sửa.

**Tech Stack:** Vite, React (JS), framer-motion, canvas-confetti, firebase (v10+), Vitest, Firebase Emulator Suite, `@firebase/rules-unit-testing`.

**Spec:** `docs/superpowers/specs/2026-10-24-gacha-20-10-design.md`

## Global Constraints

- Giao diện bằng **tiếng Việt**; tên biến/hàm bằng tiếng Anh; comment tiếng Việt.
- **Mobile-first**, hồng pastel + kem, đỏ đô làm màu nhấn, font viết tay cho tiêu đề (Google Fonts "Pacifico" hoặc "Dancing Script").
- Cánh hoa pháo giấy dùng `confetti.shapeFromText({ text: '🌸' })`, bật `disableForReducedMotion: true`.
- Cấu hình Firebase đọc từ `import.meta.env.VITE_FIREBASE_*`; **không commit** `.env.local`.
- Chuẩn hóa tên `normName` = trim, bỏ dấu, lowercase, gộp khoảng trắng.
- `deviceId` = UUID lưu trong `localStorage`, khóa `gacha2010.deviceId`.
- Firestore: `prizes/{prizeId} {name, imageUrl, order}`, `config/wishes {templates: string[]}`, `game/state {remaining: string[], assignments: {[normName]: {name, prizeId, wish, drawnAt: number}}, devices: {[deviceId]: normName}}`.
- Ảnh quà là URL, không dùng Firebase Storage.
- YAGNI: không âm thanh, không bảng xếp hạng, không upload ảnh, không đa admin.
- Thư mục chưa là git repo: Task 1 chạy `git init`.

## Review Focus

Các đầu vào spec ngầm hiểu nhưng không nói rõ, dễ làm hỏng nhất (mỗi dòng có test ở task tương ứng):

1. Tên rỗng / chỉ toàn khoảng trắng / rất dài / có emoji hoặc dấu → không cho bốc, hoặc cắt còn tối đa 30 ký tự (Task 2, 7).
